ログイン

PC で tools/start-news-server.bat を起動したうえで http://localhost:8790/admin/news.html から開いてください。

GitHub に公開したサイトから、ブラウザだけでお知らせを更新できます（GitHub トークンが必要）。

トークン作成: GitHub → Settings → Developer settings → Personal access tokens → リポジトリへの Contents 書き込み 権限を付与。
初回のみ assets/js/news-github-config.example.js を news-github-config.js にコピーしてユーザー名等を保存できます。
