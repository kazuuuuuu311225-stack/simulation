1. 音の三要素とは

私たちが感じる音の違いは、大きく3つの要素に分けられます。

  • 高さ … 周波数 f［Hz］が高いほど高い音
  • 大きさ … 振幅 A が大きいほど大きい音
  • 音色 … 波形の形（正弦波 · 矩形波 · 鋸波 · 三角波など）
y = A × 波形（2π f t）

波形の表示速度（Canvas のみ）

Canvas 上の波は見やすいよう遅く表示します。「再生」する音は常に実際の周波数です。

Canvas 表示1/600 倍速
表示上の1周期約1.4 s
音の再生実際の f
Canvas は実際の 600分の1 の速さで波が動きます。f の数値は実際の周波数です。
等倍モード … 440 Hz なら 1 周期 ≈ 2.3 ms と速く、ほとんど見えません。これが実際の波の速さです。

2. 高さ（周波数）のシミュレーション

正弦波の波の間隔が周波数 f に対応します。f が大きいほど波が密になり、高い音になります。

振幅固定 · 周波数だけ変化 — Canvas 1/600 倍速

3. 大きさ（振幅）のシミュレーション

波の高さ（振幅 A）が大きいほど、音は大きく聞こえます。周波数は 440 Hz 固定です。

同じ f・A でも波形の形が違うと、聞こえ方（音色）が変わります。

6. 三要素と波形の関係まとめ

  1. 高さ … 周波数 f［Hz］で決まる。f↑ → 波の間隔↓ → 高い音。
  2. 大きさ … 振幅 A で決まる。A↑ → 波の高さ↑ → 大きい音。
  3. 音色 … 波形の形で決まる。同じ f でも正弦波と矩形波では響きが違う。
  4. Canvas の波形と Web Audio の音は同じパラメータで連動している。
  5. 実際の楽器の音は、基本波に加え倍音（高次の波）が混ざって音色が決まる。
