グラフの見かた

上：Q(t) — 直列につながっているので、Cs も Cp も同じ Q。
下：V(t) — V₁・V₂・Vp はつねに足すと電池の電圧になります。

回路の抵抗

—

目で追えるように、大きめの抵抗にしてあります。

① 直列：Q が共通になる理由

C₁ と C₂ の間の部分は、外のどこともつながっていない「島」です。もともと電気的に中性なので、C₁ 側に −Q が来れば C₂ 側には必ず +Q が現れます。

どのコンデンサにも同じ Q

V = Q/C なので、容量が小さいほど電圧が大きい。合成すると 1/Cs = 1/C₁ + 1/C₂ となり、Cs は元のどれよりも小さくなります。

② 並列：V が共通になる理由

C₃ と C₄ は同じ 2 つの点の間につながっているので、両端の電位差はまったく同じです。

Cp = C₃ + C₄

Q = CV なので、容量が大きいほど電荷が多い。全体の電荷は Q₃ + Q₄ で、これが合成容量が足し算になる理由です。

③ 複合回路の解き方

  • まずまとめられる所からまとめる：Cs と Cp を求める
  • Cs と Cp は直列 → 1/Ctotal = 1/Cs + 1/Cp
  • 全体の電荷 Q = CtotalV を出す
  • 直列なので、この Q が Cs にも Cp にも共通
  • Vs = Q/Cs、Vp = Q/Cp と逆にたどる

④ 検算のしかた

答えが出たら、必ず 2 つの式で確かめます。

V₁ + V₂ + Vp = V

一周まわると電位はもとに戻る（キルヒホッフの第2法則）。

Q₃ + Q₄ = Q

並列部に入った電荷は、C₃ と C₄ に分かれるだけで増えも減りもしません。この 2 つが合っていれば計算はほぼ正しいです。

ここがポイント

  • 直列は Q が共通・並列は V が共通。この 2 つを取り違えないことが最重要。
  • 直列 1/Cs = 1/C₁ + 1/C₂（元より小さくなる）／並列 Cp = C₃ + C₄（足し算で大きくなる）。
  • まとめて Q = CtotalV を出し、そこから V = Q/C で各部にもどる。
  • 検算は V₁+V₂+Vp = V と Q₃+Q₄ = Q。
