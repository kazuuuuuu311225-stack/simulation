操作パネル

● ブラッグ条件 2d sinθ=nλ が成立する正解（結晶＋λ,θ,d 自動 · 次数 n は下で指定）
● 反射次数 n を指定（θ を自動計算してブラッグ成立）
λ と d を変えて 2d sinθ = nλ を満たすと、反射波とラウエ斑点が強く輝きます。

ここがポイント

  • X線は電磁波（波）— 波長 λ と振動数 ν = c/λ
  • 結晶の面間隔 dで反射した波が干渉する
  • ブラッグ条件 2d sinθ = nλ が成立すると強い反射
  • 回折スポット（ラウエ斑点）の位置は λ, d, θ, n で決まる
  • X線回折法は結晶構造を調べる基本手法
