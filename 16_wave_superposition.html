1. 波の合成とは

2つ以上の波が同じ場所を通ると、各点での変位は足し算で決まります。進行方向が逆でも、振動数が違っても、合成の原理は同じです。

  • 合成波：y = yA + yB
  • 右向き：sin(kx − ωt)  |  左向き：sin(kx + ωt)
  • 同位相 … 強め合い  |  逆位相 … 弱め合い
y = A₁ sin(k₁x ∓ ω₁t) + A₂ sin(k₂x ∓ ω₂t + φ)  （∓ で進行方向）

2. 2つの波（波A · 波B）

青が波A、赤が波B。横軸は距離 x［m］、縦軸は変位 y［m］です。

左：波A  |  右：波B — 進行方向はスライダー下のボタンで切り替え

4. 同位相の合成（強め合い）

位相 φ = 0。同方向・同 λ・同 f のとき、振幅 ≈ A₁ + A₂ になります。

同位相（同方向）：合成振幅 ≈ A₁ + A₂ = 0.16 m

5. 逆位相の合成（弱め合い · 打ち消し）

位相 φ = π。同方向・A₁ = A₂ なら完全に打ち消し。逆方向・同 f なら定常波になります。

逆位相（同方向）：合成振幅 ≈ |A₁ − A₂| = 0.00 m

7. 高校生向けまとめ

  1. 波の合成は変位［m］の足し算。y = yA + yB。
  2. 右向き sin(kx−ωt)、左向き sin(kx+ωt)。A・B それぞれ選べる。
  3. 同方向・同位相 → 強め合い。同方向・逆位相 → 弱め合い（A₁=A₂ で打ち消し）。
  4. 逆方向・同 f・同 λ → 定常波（節と腹）。これも合成の一例。
  5. v = fλ［m/s］、T = 1/f［s］。f₁ と f₂ は独立に設定できる。
