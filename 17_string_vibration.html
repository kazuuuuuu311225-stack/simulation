1. 弦の振動とは何か

弦は両端が固定された状態で、横方向に振動します。振動の形は自由に選べず、弦の長さと固定条件で決まった固有振動モードだけが現れます。

  • 左右の端は動かない → 節（変位ゼロ）
  • 弦の中央付近など振幅が最大の点 → 腹
  • 時間とともに形は保ったまま、大きさだけが周期的に変化する

両端固定の弦 — 1次モードで上下に振動（アニメーション）

節（固定端） 腹（振幅最大）

2. 固有振動とは何か

弦が自然に振動する形を固有振動（モード）といいます。n 次モードでは弦上に n 個の腹が現れます。

  • 1次 … 基本振動。中央に腹1つ（両端は節）
  • 2次 … 倍振動。中央に節、腹2つ
  • 3次 … 3倍振動。節2つ（内部）、腹3つ

4. 振動の名前（基本振動 · 倍振動）

音楽や音響で使われる呼び方と、物理学でのモード番号 n の対応です。

n = 1基本振動（fundamental）
n = 2第2倍音（2nd harmonic）
n = 3第3倍音（3rd harmonic）

5. 固有振動数の基本式

両端固定の弦では、波長 λ_m と固有振動数 f_m が次の関係で決まります（v は弦中の波の速さ）。

λ_m ＝ 2L / m　　（m ＝ 1, 2, 3, …）

f_m ＝ m·v / (2L)　　（m ＝ 1, 2, 3, …）

6. 弦の長さ · 張力 · 線密度と固有振動数

スライダーで L · T · μ を変えると、固有振動数がリアルタイムで更新されます。

v ＝ √(T/μ)。L↓ · T↑ · μ↓ なら v↑ → f_m は高くなる。

7. 身の周りにある弦の固有振動

🎸 ギターの弦

弦長 L と張力 T を変えて f₁ を変える。指板で押さえる位置が短いほど高い音になる。

🎻 バイオリンの弦

4本の弦それぞれに異なる L · T · μ が設定され、異なる f₁ を持つ。

🎹 ピアノの弦

低音は長く太い弦（μ が大）、高音は短く細い弦。各鍵が固有振動数 f₁ を持つ。

🪕 三味線の弦

3本の弦が異なる太さ · 張力で異なる f₁ を持ち、和音やメロディを奏でる。

💨 電線の風振動

風で横波が励起され、固有振動モードで振動。ギター弦と同じ「両端固定に近い弦」の原理。

8. 高校生向けまとめ

  1. 弦は両端固定で、決まった形（固有振動モード）だけが振動する。
  2. 1次（基本振動）· 2次 · 3次 … と、節と腹の数が増えるモードがある。
  3. λ_m ＝ 2L/m、f_m ＝ m·v/(2L)（m ＝ 1, 2, 3, …）。v ＝ √(T/μ)。
  4. L↓ · v↑ なら f_m は高くなる（短い弦 · 強い張力 · 軽い弦 → 高い音）。
  5. ギター · バイオリン · ピアノ · 三味線 · 電線など、身の回りに弦の固有振動がある。
