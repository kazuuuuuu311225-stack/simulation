高校の対応表（このモード）

量値のイメージ

① まず覚える式

U = (f/2) nRT

理想気体の内部エネルギーは温度だけの関数。体積や圧力が変わっても、T が同じなら U は同じです。

  • 単原子：f=3 → U = (3/2)nRT
  • 二原子：f=5 → U = (5/2)nRT

② 4つの変化（何が一定？）

  • 定容：V 一定 → P∝T、仕事 W=0、ΔU=Q
  • 定圧：P 一定 → V∝T、仕事あり、ΔU=(f/2)nRΔT
  • 等温：T 一定 → PV一定、ΔU=0、Q=−W
  • 断熱：Q=0 → PVγ一定、ΔU=W（符号に注意）

③ グラフの形

  • 定容＝PV図で縦線
  • 定圧＝PV図で横線
  • 等温＝双曲線（PV=一定）
  • 断熱＝等温より急な曲線（PVγ=一定）

④ 授業での使い方

  • 等温 → 「T一定だから U も動かない」を確認
  • 定容 → 「箱は動かず、速さと P だけ変わる」
  • 定圧 → 「活塞が動き V が T に比例」
  • 断熱 → 「膨張すると矢印が短くなる＝冷却」

ここがポイント（高校物理）

  • 理想気体では U = (f/2)nRT。だから等温変化では ΔU = 0。
  • 第一法則 ΔU = Q + W（仕事の符号定義に注意。ここでは気体がする仕事を負にとる流儀も多い）。
  • 断熱では Q=0 なので ΔU = W。膨張すれば T↓・U↓。
