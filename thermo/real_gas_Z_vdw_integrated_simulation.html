① Z とは何か

Z = PV / (nRT)

理想気体では PV = nRT なので、この比は常に 1 です。実在気体では圧力や体積の関係がずれるため、Z も 1 からずれます。

  • Z = 1 … 理想気体として扱ってよい
  • Z < 1 … 理想より圧縮されやすい（引力）
  • Z > 1 … 理想より圧縮しにくい（分子の体積）

② a と b（高校のイメージ）

  • a（引力） … 分子同士が引き合う → 壁を押す力が弱まる → 圧力↓ → Z<1
  • b（分子体積） … 分子自身が場所を占める → 高圧で効く → Z>1

CO₂ は a が大きくずれやすい。H₂ は a・b が小さく Z≈1 に近いです。

③ 画面の見方

  • 式バー … P×V÷(nRT)=Z に数値が入る
  • 目盛り … 針が左＝Z<1、中央＝1、右＝Z>1
  • 左グラフ … 同じ T で理想と実在の P–V
  • 右グラフ … 圧力を変えたときの Z（水色が理想）

④ 授業の進め方

  • プリセット①②③をこの順に押す
  • 毎回「式バーの Z」と「目盛りの針」を指差す
  • 最後に物質を H₂ に変えて、ずれが小さくなることを比較

ここがポイント（高校物理）

  • 理想気体は PV = nRT → 圧縮係数はいつも Z = 1。
  • 実在気体は分子間力と分子体積のため、同じ T・V でも圧力が理想と違う → Z ≠ 1。
  • Van der Waals は「理想＋a（引力）＋b（体積）」の近似。高校ではまず Z<1 / Z≈1 / Z>1 の意味を押さえる。
