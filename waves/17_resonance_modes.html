1. 固有振動とは何か

物体がその物体固有の形で振動することを固有振動といいます。外力の周波数に関係なく、物体の性質（形状・材料・境界条件）で決まる振動モードがあります。

  • 弦 … 1次（中央に腹）· 2次（中央に節）· 3次（節2つ）のモード
  • 空気柱（閉管） … 1次 · 3次 · 5次 … と奇数倍音のみ
  • 各モードは節（動かない点）と腹（振幅最大）の配置が決まっている

弦の1次モード — 両端が節、中央が腹

2. 固有振動数とは何か

物体が自然に振動する周波数を固有振動数といいます。

  • 弦 … 長さ L · 張力 T · 線密度 μ で決まる（L が短い · T が大きい → 高い音）
  • 空気柱 … 管の長さで決まる（短い管 → 高い音）
  • n 次モードの固有振動数：弦なら fn = n f1、閉管なら fn = (2n−1) f1
fn（弦）＝ n × f1　　fn（閉管）＝ (2n−1) × f1
f₁（1次）220 Hz
f₂（2次）440 Hz
f₃（3次）660 Hz
閉管 f₃660 Hz

3. 身の周りにある固有振動の例

🎠 ブランコ

一定の固有周期で揺れる。同じタイミングで押すと振幅が大きくなる（共振）。

🏢 建物の揺れ

地震の周波数が建物の固有振動数と一致すると共振し、大きく揺れる。

🎸 ギターの弦

弦の長さと張力で f₁ が決まり、指板で有効長を変えて音程を変える。

🎵 空気柱（リコーダー）

指孔で管の長さを変え、空気柱の固有振動数を変えて音程を変える。

🚗 車のエンジン音

特定の回転数で車体や内装が共振し、うるさく感じることがある。

📡 電子レンジ

マグネトロンが約 2.45 GHz の共振周波数でマイクロ波を発生させ、水分子を加熱する。

4. 共鳴 · 共振とは何か

周期外力の周波数が固有振動数と一致すると、振幅が大きくなる現象を共鳴（共振）といいます。

  • 共振条件：fext ≈ fnatural
  • 一致度が高いほど振幅が大きくなる（Q 値が大きいほど鋭い共振）
  • 一致から外れると振幅は急速に小さくなる
共振条件：fext ＝ fnatural
外力周波数を f₁ に合わせると振幅が最大になります（§6 で操作）。

6. 共鳴のシミュレーション

固有振動数 f₀（＝ f₁）に対して、外力の周波数 fext を変えて振幅の変化を見ます。

左：共振曲線 · 右：強制振動の振幅（fext ≈ f₀ で最大）

9. 高校生向けまとめ

  1. 固有振動 … 物体固有の振動モード（弦の1次 · 2次 · 3次、閉管の奇数倍音など）。
  2. 固有振動数 … そのモードで自然に振動する周波数 fn。弦なら fn = n f₁。
  3. 共鳴 · 共振 … fext = fnatural のとき振幅が最大になる。
  4. ブランコ · 建物 · 楽器 · 空気柱 · 電子レンジなど、身の回りに固有振動がある。
  5. 楽器の音色は基本振動に加えた倍音（固有モードの重ね合わせ）で決まる。
  6. Canvas でモードと共振を、Web Audio で実際の音を確認できる。
