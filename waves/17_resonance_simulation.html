1. 共振・共鳴とは何か

周期外力の振動数が物体の固有振動数と一致すると、振幅が大きくなる現象を共振（共鳴）といいます。

  • 一致度が高いほど振幅が大きくなる
  • 一致から外れると振幅は急速に小さくなる
  • ブランコを同じタイミングで押すと振れ幅が増える — 身近な例
共振条件：fext ≈ f₀

2. ブランコでの共振イメージ

左：周期に合わせて押す → 振れ幅が増える（共振）。右：周期がズレる → 振れ幅は増えない。

左＝fext ≈ f₀（共振） · 右＝fext ≠ f₀（非共振）

3. 固有振動数と外力周波数の関係

物体には固有振動数 f₀ があり、外力の周波数 fext を変えると振幅の大きさが変わります。

x″ + 2β x′ + ω₀² x = F cos(ωext t)
ω₀ = 2π f₀　　ωext = 2π fext
fext を f₀ に近づけると振幅が最大になります（§4〜7 で操作）。

8. 共振の例

🥂 ガラスが割れる

特定の音の周波数がガラスの固有振動数と一致すると、微小な力でも振幅が増大し、割れることがある。

🏢 建物の揺れ

地震の周期が建物の固有周期と一致すると共振し、想定以上に大きく揺れる。

🎻 楽器の胴の共鳴

弦やリードの音が胴（空気・板）の固有振動数と一致すると、音が大きく響く。

🎠 ブランコ

固有周期に合わせて押すと振幅が増える。ずれたタイミングでは増えない — 本ページ §2 の図。

9. 高校生向けまとめ

  1. 共振 … 外力の振動数 fext が固有振動数 f₀ と一致すると振幅が大きくなる。
  2. 減衰付き強制振動：x″ + 2β x′ + ω₀² x = F cos(ωext t)。β が小さいほど共振が鋭い。
  3. fext ≈ f₀ のとき定常振幅 A が最大。離れると A は急速に小さくなる。
  4. ブランコ · ガラス · 建物 · 楽器など、身の回りに共振の例がある。
  5. fext は 0〜3 Hz（ブランコ・建物など）— Canvas の表示速度（1/600 / 等倍）は見やすさのために変えているだけ。
