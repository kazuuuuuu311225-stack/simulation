実験の設定

リングの上をドラッグすると、中心からの距離 r と空気層の厚さ t を確かめられます。

いまの計算

① 空気層の厚さ

t ≈ r² / (2R)

レンズの球面を、中心近くで放物線とみなした近似です。

② 暗環の条件

2n·r²/(2R) = mλ　→　r = √(mλR/n)

—

③ 明環の条件

r = √((m+½)λR/n)

—

④ 中心が暗い理由

中心では r = 0 → t = 0 → 光路差 0

それでも下面反射で π ずれるため、2 つの光は逆位相になって打ち消し合います。これが m = 0 の暗環です。

リングの半径

同じ 2nt なのに、なぜ並び方が違う？

くさび型：等間隔

t = x·θ は x に比例

xm = mΔx　（Δx は一定）

厚さが一定の割合で増えるので、縞も等間隔に並びます。

ニュートン：外ほど詰まる

t = r²/(2R) は r の2乗に比例

rm = √(mλR/n) ∝ √m

外側では少し進むだけで t が大きく増えるので、リングの間隔がどんどん狭くなります。

共通しているところ

どちらも「空気層を往復する光路差 2nt」と「下面での π 反転」。 だから t = 0 の場所（くさびの左端・リングの中心）はどちらも暗いのです。

① なぜ 2nt なのか

上のガラスの下面で反射する光1と、すき間を通って下のガラスの上面で反射する光2 を比べます。光2 はすき間を往復するので、光路差は厚さの 2 倍です。

ΔL = 2 n t

すき間が空気なら n = 1 なので、そのまま 2t になります。水などで満たすと n 倍になり、縞は細かくなります。

② いちばん間違えやすい所

t = 0 の場所は「明」ではなく「暗」です。

  • 上面（ガラス→空気）：屈折率が小さくなる → 反転なし
  • 下面（空気→ガラス）：屈折率が大きくなる → π 反転

反転が 1 回（奇数）なので条件が入れかわり、暗 : 2nt = mλ、明 : 2nt = (m+½)λ となります。くさびの接触端も、ニュートンリングの中心も暗くなります。

③ くさび型：縞の間隔

となり合う暗線では 2nt の差がちょうど λ。t の差は Δt = λ/(2n) で、t = xθ だから：

Δx = λ / (2nθ) = λL / (2nD)

逆に、縞の間隔 Δx を測れば、はさんだ物の厚さ D や波長 λ を求められます。これが実験問題の定番です。

④ ニュートンリング：半径

中心から距離 r の所の空気層の厚さは、球面の近似から t ≈ r²/(2R)。これを条件式に入れると：

暗 r = √(mλR/n)　　明 r = √((m+½)λR/n)

r が √m に比例するので、外側ほどリングの間隔が狭くなります。くさび型が等間隔なのと対照的です。

ここがポイント

  • どちらも空気層の往復による 光路差 2nt と、下面での π 反転で決まる。
  • π 反転が 1 回（奇数）なので条件が入れかわり、暗 2nt = mλ・明 2nt = (m+½)λ。
  • くさび型：t = xθ より Δx = λL/(2nD)。縞は等間隔。
  • ニュートンリング：t = r²/(2R) より r = √(mλR/n)。中心は暗く、外側ほど間隔が狭い。
