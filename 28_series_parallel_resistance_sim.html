第23章 — 電流

直列・並列 — 合成抵抗と電子の流れ

← 電磁気 · 第23章

直列は「足し算」、並列は「道が増える」

抵抗をつなぎ方によって合成抵抗 Rtotal が変わります。 電子（青い粒）の流れ方で、なぜ電流 I が変わるかを直感的に理解できます。

  • 直列：1 本の道を順番に通る → Rtotal = R1 + R2（妨害が足し算）
  • 並列：2 本の道に分かれる → 1/R = 1/R1 + 1/R2（流れやすくなる）
  • 電流 I = V / Rtotal · 発熱 Q = I² Rtotal t
直列 R = R1 + R2 · 並列 R = R1R2/(R1+R2) · I = V/R · Q = I²Rt

シミュレーション

● 青 ＝ 自由電子（右向き · 逆流なし） — 灰色 ＝ 導線 → 黄 ＝ 電流 I（+ → − · 電子の逆向き） 抵抗の色 青→赤 ＝ 発熱 Q
