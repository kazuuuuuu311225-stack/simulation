ここがポイント（高校物理）

  • 等加速度直線運動：x(t) = x₀ + v₀t + ½at²、v(t) = v₀ + at（x₀ = 0 から）
  • 位置ビュー：x 軸上のボールと白枠の速度矢印で、向きと大きさを直感的に確認
  • x–t グラフ：a ≠ 0 なら放物線、a = 0 なら傾き v₀ の直線
  • v–t グラフ：傾き a の直線 — 面積（積分）が変位 Δx に対応
  • a < 0：速度が減り、折り返し点（v = 0）以降は x が減少し始める
