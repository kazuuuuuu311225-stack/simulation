重心の計算

原点 O を Canvas 左下付近とします。各質点の位置 (x, y) と質量 m から、質量のつり合い点が重心 G です。

① x 方向

xG = (m₁x₁ + m₂x₂ + m₃x₃) / (m₁ + m₂ + m₃)

→ xG = — m

② y 方向

yG = (m₁y₁ + m₂y₂ + m₃y₃) / (m₁ + m₂ + m₃)

→ yG = — m

コントロール

質点 2（黄）
質点 3（赤）

xG = (m₁x₁ + m₂x₂ + m₃x₃) / (m₁ + m₂ + m₃)
yG = (m₁y₁ + m₂y₂ + m₃y₃) / (m₁ + m₂ + m₃)

色付きの質点をドラッグして位置を変えてください。質量を大きくした質点ほど、重心 G はその方向へ引き寄せられます。

ここがポイント（高校物理）

  • 重心 G は質量のつり合い点
  • x_G = (m₁x₁ + m₂x₂ + …) / (m₁ + m₂ + …)
  • 質量を大きくすると G がその質点側へ移動
  • 対称な剛体では重心が幾何中心に来ることが多い
