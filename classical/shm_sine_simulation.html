単振動（バネ＋質点）

変位 x(t) の正弦波

単振動 HUD

走行状態
A, k, m を設定して「スタート」

パラメータ

A = — m

k = — N/m

m = — kg

φ = — rad

角振動数・周期

ω = √(k/m)

→ ω = — rad/s

T = 2π / ω

→ T = — s

現在の変位

x(t) = A cos(ωt + φ)

t = — s

→ x = — m

コントロール

ここがポイント（高校物理）

  • 復元力 F = −kx より m d²x/dt² = −kx。解は x(t) = A cos(ωt + φ)
  • 振幅 A・バネ定数 k・質量 m を変えると ω と T が連動して変わる
  • グラフの赤い縦線が現在時刻 t。1周期分（T）を強調表示
