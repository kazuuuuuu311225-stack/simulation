計算過程

バットの法線 n に対する入射角 θin と反射角 θout（|θout| = |θin|）から v′ を求め、運動量を計算します。

① 入射角 θin（法線 n に対する角）

θin = ∠(v, n)

→ θin = —°

② 衝突前の速度成分

vx = v cos φ　　vy = v sin φ

→ vx = — m/s、vy = — m/s

③ 反射角 θout

|θout| = |θin|（法線の反対側）

→ θout = —°

④ 衝突後の速度成分

v′ = v′t t + v′n n　（v′n = −vn）

→ v′x = — m/s、v′y = — m/s

⑤ 力積（やさしい言い方）

I = Δp = p′ − p（ボールの運動量の変化）

→ Ix = —、Iy = — kg·m/s

大きさ |I| = — kg·m/s

ボール→バット = −I（向きが反対・大きさ同じ）

→ (−I)x = —、(−I)y = — kg·m/s

⑥ 運動量

衝突前 p = m v

→ px = —、py = — kg·m/s　大きさ = —

衝突後 p′ = m v′

→ p′x = —、p′y = — kg·m/s

大きさ |p′| = — kg·m/s　向き = —°

⑦ 運動エネルギー（鏡面反射）

K = ½ m v²　→　|v′| = |v| なので K′ = K

K = — J　（跳ね返り後も同じ）

ここがポイント（高校物理）

  • 運動量 p = mv（ベクトル量 · kg·m/s）
  • 力積 I = Δp = p′ − p（ボールが受けた力の時間積分）
  • ボール→バットの力積 = −I（作用・反作用）
  • 鏡面反射モデル：法線 n に対し |θin| = |θout|、速さ |v| は保存
  • 鏡面反射では |p| = |p′|（運動エネルギーも K′ = K）

入射角と反射角

|θout| = |θin|（法線の反対側）
