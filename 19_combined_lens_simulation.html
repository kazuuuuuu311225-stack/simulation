2枚のレンズ — 合成焦点と像

← 波動 · 第19章

2枚のレンズとは？（高校物理）

望遠鏡やカメラのレンズは、実際には1枚ではなく複数枚重なっています。 レンズ1で一度屈折した光が、レンズ2でもう一度屈折します。 2枚をまとめて1枚のレンズのように考えたときの「強さ」が合成焦点距離 feqです。

1/feq = 1/f₁ + 1/f₂ − d/(f₁ f₂)
  • f₁ … レンズ1の焦点距離（凸＝正、凹＝負）
  • f₂ … レンズ2の焦点距離（凸＝正、凹＝負）
  • d … 2枚のレンズ中心間の距離（常に正）
  • feq … 合成焦点距離。2枚全体の「集め方・散らし方」
  • a … 物体からレンズ1までの距離（物距）
  • b … レンズ2から最終像までの距離（像距）
  • m … 合成倍率 = m₁ × m₂（2回の像の倍率の積）
符号のルール（1枚のときと同じ）： 凸レンズ f > 0、凹レンズ f < 0。 実像の b は正、虚像の b は負。 左から入った平行光が交わる点が合成焦点 Feq（発散するときは延長線の交点）。

光の進み方 — 3ステップ

  1. 平行光が入射（青）
    左から光軸に平行な光がたくさん入ってきます。太陽遠方の光をイメージしてください。
  2. レンズ1で屈折（紫）
    凸なら焦点 F₁′ 方向へ曲がり、凹なら発散して延長線が虚焦点へ向かいます。
  3. レンズ2で再屈折（ピンク）
    さらに曲がって交わる点が Feq（黄 ✦）。 凹レンズを含むと feq が小さくなったり、発散系になります。

物体の像 — 2段階で考える

物体から出た光も、同じようにレンズ1 → レンズ2の順で屈折します。

  1. レンズ1だけの像
    1/f₁ = 1/a + 1/b₁ で b₁ を求め、像1の位置が決まります。
  2. 像1をレンズ2の「物体」として像2を求める
    1/f₂ = 1/a₂ + 1/b で最終像 b を求めます（a₂ = レンズ2 − 像1の位置）。 合成倍率 m = m₁ × m₂ = (−b₁/a) × (−b/a₂) です。
操作のヒント： d を大きくすると 1/feq の「−d/(f₁f₂)」の項の影響が増え、合成焦点距離が変わります。 ⏸ ボタンで光線を止めると、交わる点や延長線をゆっくり確認できます。

よくある組み合わせ

  • 凸＋凸（d が小さい） … feq は短く（強く集める）。望遠レンズのイメージ
  • 凸＋凹 … 凹が発散役。望遠鏡の eyepiece 付近の構成に近い
  • d を大きくする … −d/(f₁f₂) の項が効き、2枚の「離れ方」が合成焦点に影響
  • feq < 0 … 全体として発散系。Feq は虚焦点（延長線の交点）
