直線運動の式（高校物理）

物体は x 軸上を動きます。初位置 x₀ = 0、初速度 v₀、加速度 a は一定とします。

① 運動の種類

a = 0 のとき → 等速直線運動（v は一定）

a ≠ 0 のとき → 等加速度直線運動

いまの運動：—

② 速度の式

v = v₀ + at

→ v = — + — · t

今の v = — m/s （t = — s のとき）

③ 位置の式

x = x₀ + v₀t + ½at²

→ x = 0 + — · t + ½ · — · t²

今の x = — m （t = — s のとき）

④ v–t グラフの読み取り

グラフの傾き = 加速度 a = — m/s²

t = 0 における v 切片 = 初速度 v₀ = — m/s

v–t グラフは直線になり、傾きが a です。

v² = v₀² + 2a(x − x₀)
